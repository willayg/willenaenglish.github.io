HOW LEARNING CONNECTS

Read → Think → Speak → Write

윌레나의 핵심은 프로그램 이름을 많이 만드는 것이 아니라, 배운 영어가 다음 활동으로 자연스럽게 이어지게 만드는 것입니다.

01

Read

교재와 영어도서관을 통해 어휘와 문장 구조를 충분히 입력합니다.

02

Think

내용을 이해하고 질문에 답하며 자신의 생각을 정리합니다.

03

Speak

원어민 수업에서 표현을 실제 대화와 발표로 꺼내 사용합니다.

04

Write

자기 문장과 저널, 과제 결과물로 영어를 다시 구조화합니다.
