# Willena Projects

This folder is the central index for the apps and databases currently being developed for Willena English.

> Existing live files have not been moved. This avoids breaking current website URLs and app links. Each project can gradually be moved into its own folder later, with redirects or compatibility files added where necessary.

## Project groups

- [Apps and platforms](./apps/README.md)
- [Databases and curriculum systems](./databases/README.md)

## Main connected system

```text
Willena Content Database
        ↓
Assessment Question Bank
        ↓
Curriculum Editor / Test Builder
        ↓
Level Tests / Student Practice / Classroom Apps
        ↓
Student Tracker / Dashboard / Parent Reports
```

## Current priorities

1. Expand and clean the Willena Content Database.
2. Complete the authored Assessment Question Bank for Levels 1–10.
3. Connect the Free Level Test and curriculum tools to the databases.
4. Import and classify textbook content, beginning with English Bus 1.
5. Develop reusable teacher and student practice tools.

## Status labels

- **Active** — currently being built or revised.
- **Existing** — already present and being reviewed or maintained.
- **Prototype** — working classroom experiment or early app.
- **Planned** — agreed direction, but not yet fully implemented.
