# Willena App Projects

This page tracks the larger platforms and smaller classroom apps discussed or developed for Willena English.

## Core platforms

| Project | Status | Purpose / current location |
|---|---|---|
| Willena Adaptive Placement Test | Active | Authored, level-based test with Phonics, Vocabulary, Listening, Grammar, Reading, Writing and Speaking sections. |
| Free Level Test | Active | Public-facing placement test at `/free-level-test/`. |
| Curriculum Editor | Active | Teacher/admin curriculum tool at `/Teachers/tools/curriculum-editor/`. |
| Teacher Test and Quiz Builder | Planned | Build printable and online assessments from reusable curriculum and assessment items. |
| Student Practice Platform | Planned | Assigned and independent vocabulary, grammar, reading, listening and speaking practice. |
| Student Tracker | Existing | Teacher-facing student score and progress display. |
| Student Dashboard | Existing | Student-facing results and progress display; score logic is being compared with Student Tracker. |
| Parent Progress and Photo App | Planned | Private family access to photos, work samples, scores, reports and teacher comments. |

## Organization rule

When an app becomes a maintained product, give it a dedicated folder under `projects/apps/` containing:

- `README.md`
- source location or source files
- database dependencies
- deployment URL
- current status and next tasks

Live apps should only be physically moved after their public URLs and internal links have been checked.
